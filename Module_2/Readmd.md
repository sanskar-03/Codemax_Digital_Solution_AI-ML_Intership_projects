# Python Password Generator

This is my Mini Project for Module 2 of my Python course. 

## Description
A simple, beginner-friendly command-line application that generates a random, secure password based on a user-defined length. It demonstrates the use of variables, loops, custom functions, and Python's built-in `random` module.

## Features
* Prompts the user to choose their own password length.
* Generates a random mix of uppercase letters, lowercase letters, numbers, and special symbols.
* Includes basic error handling (try/except) in case the user enters invalid text instead of a number.

## How to Run
1. Make sure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Navigate to the folder containing this project.
4. Run the script using the command: `python main.py`
