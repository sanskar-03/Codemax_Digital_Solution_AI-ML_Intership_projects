# StudyForge

StudyForge is a Django-based learning and productivity platform.

## Features

- User authentication
- Learning subjects
- Topic management
- Progress tracking
- Smart priority recommendations
- Focus sessions
- Countdown timer
- Knowledge checks
- Quiz scoring
- Study assistant architecture
- Learning reports
- Responsive interface

## Run

    python manage.py migrate
    python manage.py runserver

Open:

    http://127.0.0.1:8000/
