## 🚀 Key Projects Breakdown

### 🔹 Module 5: StudyForge (AI Tools & Mini Project)
An intelligent learning and focus-management platform integrating AI assistance and automated self-assessment:
- **AI Engine**: Contextual study assistant and personalized recommendations[cite: 2].
- **Focus Mode**: Structured pomodoro timer and session tracking[cite: 2].
- **Interactive Quizzes**: Dynamic topic-based question generation and scoring[cite: 2].
- **Analytics**: Real-time study metrics and progress reporting[cite: 2].

### 🔹 Module 6: TravelShield (Final AI & ML Capstone)
An enterprise-grade, end-to-end travel risk assessment system powered by machine learning:
- **ML Pipeline**: Feature-engineered travel risk classification model trained on custom risk datasets[cite: 1].
- **Inference Service**: Real-time risk probability calculation and risk-level categorization[cite: 1].
- **Automated Weather & Report Pipeline**: Real-time weather integration and automated travel advisories[cite: 1].
- **Asynchronous Task Queue**: Celery and Redis integration for scalable report generation[cite: 1].
